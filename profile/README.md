# Orizon Software Foundation
## What we do 
The Orizon Software Foundation is a non-profit that maintains Free Software ( not free as in beer free as in libre) . We believe software should be free, open source, and reliable. No user should have to worry with software that is free to use, free to modify, free to inspect.
